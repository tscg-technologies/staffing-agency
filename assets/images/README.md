# Staffing Agency — Website Image Assets

This folder is the target directory for all high-resolution photographic and illustrative assets for the **STAFFING AGENCY** demonstration website.

## Status: Placeholder Mode Active
All web pages currently utilize responsive, styled CSS/SVG container placeholders with fixed aspect ratios (16:9, 4:3, 1:1, 21:9) and fallback indicators to prevent Cumulative Layout Shift (CLS) and eliminate broken image icons.

## How to Deploy Real Images
1. Generate the desired assets via Google Flow or your preferred AI image generator following the comprehensive prompts provided in [IMAGE-GENERATION-GUIDE.md](../../IMAGE-GENERATION-GUIDE.md).
2. Save the generated images into this directory (`assets/images/`) using the exact filenames specified in the guide.
3. The image placeholder markup automatically displays the image overlay `<img src="assets/images/<filename>" alt="...">` when present.
